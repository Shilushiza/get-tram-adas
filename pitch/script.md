### Если демо сломалось
- Не извиняться, сказать «покажу на снимках» и перейти на запасные слайды B1-B5 (те же шаги, те же кадры).
- Если не отвечает API: перезапуск через значок в трее, «Перезапустить серверы» (около 10 с). Если не поднялось за 10 с, переходить на снимки.
- Если зависла 3D-сцена: вкладка **2D** работает без WebGL.
- Если нет сети: ИИ-разбор берётся из кеша, остальное работает локально.
- Рекомендуется до защиты записать экранный ролик демо на 2 минуты (Win+G, Xbox Game Bar) и положить рядом как третий уровень запаса.

## Ответы на 5 вероятных вопросов жюри

1. **Как вы находите срабатывания, если в JSON поля `m_*_act` пустые?**
   Срабатывания берём из CSV: `dangObjAct/RealAct`, `trafLightAct/RealAct`, `speedLimitAct/RealAct`, тормоза, рукоятки. JSON даёт тип объекта (`goal_obj_type`), уровень предупреждения (`m_warn_level`), режим автомата. Файлы склеены по времени: совпадение 100%, корреляция скорости 0,998. Срабатывания ближе 8 с объединяются в один эпизод.

2. **Чем гарантируется, что ИИ не выдумывает?**
   Факты собирает код (`backend/events.py`), не модель. Модель получает только список фактов с временем и полем и пересказывает их по четырём разделам ТЗ, температура 0,1. Причина пишется только при подтверждающем поле. Текст модели стоит над фактами; если они расходятся, верим фактам. Без ключа модели факты и дашборд работают полностью.

3. **Почему важных так много: 3 602 из 13 357? И почему на сайте 3 591?**
   Важность сейчас считается правилом: любое торможение по препятствию, рельсовый тормоз или юз это «важно», аварийный или экстренный тормоз «критично». Следующий шаг: учитывать падение скорости. 3 602 это все типы по API; на «Обзоре» по умолчанию скрыто ограничение скорости, поэтому там 3 591. Число 3 099 в документах это эпизоды по препятствию, а не важные.

4. **Насколько точна реконструкция?**
   Скорость, тормоза, сигналы и управление взяты из записи. Положение объекта и светофора условное: дистанции в данных нет. Время в CSV до секунды, шаг записи до 5-7 с, порядок событий внутри секунды не установлен. Всё это выводится в разделе «Ограничения анализа» каждого эпизода.

5. **Как это внедрить у нас?**
   Вкладка «Загрузка»: CSV поездки (JSON по желанию) проходит тот же конвейер, эпизоды появляются по мере нахождения. Приложение ставится на Windows одним скриптом, ярлык поднимает API и сайт локально, данные не уходят в облако (кроме запроса к модели, если включён ИИ-разбор). Для точной реконструкции нужна дистанция до объекта и метки времени у видео камер.

Запасной вопрос про ML: прогноз «торможение по препятствию в ближайшие 10 с» даёт PR-AUC 0,07 против 0,026 у случайного (лифт около 2,7), ROC-AUC 0,76 при разбиении по вагонам. Как прогноз слабо, как разбор факторов полезно (ML_REPORT.md).
