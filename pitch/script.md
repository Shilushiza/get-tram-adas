## Ответы на 5 вероятных вопросов жюри

1. **Откуда срабатывания, если в JSON поля `m_*_act` почти всегда `No`?**
   Из CSV: `dangObjAct/RealAct`, `trafLightAct/RealAct`, `speedLimitAct/RealAct`, тормоза, рукоятки. JSON даёт тип объекта (`goal_obj_type`), уровень предупреждения (`m_warn_level`), режим автомата. Склейка по времени (`merge_asof`, допуск 3 с): совпадение 100%, корреляция скорости 0,998. Срабатывания ближе 8 с объединяются в один эпизод.

2. **Чем гарантируется, что ИИ не выдумывает?**
   Факты собирает код (`backend/events.py`). Модель получает только список фактов с временем и полем и пересказывает его по разделам, температура 0,1. Причина пишется только при подтверждающем поле, иначе «не установлена». В окне ИИ-анализа прямо написано: если текст расходится с фактами, верьте фактам. Без ключа модели факты, дашборд и реконструкция работают полностью.

3. **Почему важных так много: 59%? И что делает Jev?**
   Важность сейчас считается правилом: торможение по препятствию, рельсовый тормоз или юз это «важно», аварийный или экстренный тормоз «критично». Следующий шаг: учитывать падение скорости (в 1 020 эпизодах по препятствию скорость упала меньше чем на 1 км/ч). Jev это лёгкая модель, отвечает «да / нет / не знаю» на три вопроса и ставит приоритет очереди. Пока в 11 проверенных ответах она всегда просит ручной разбор, поэтому её вердикт подсказка, а не решение.

4. **Насколько точна реконструкция?**
   Скорость, тормоза, сигналы и управление взяты из записи. Положение объекта и светофора условное: дистанции в данных нет, поэтому «~6 м» подписано «условно». Время в CSV до секунды, шаг записи до 5-7 с, порядок событий внутри секунды не установлен. Всё это выводится в разделе «Ограничения анализа» каждого эпизода.

5. **Как это внедрить у нас?**
   Вкладка «Загрузка»: CSV поездки (JSON по желанию) проходит тот же конвейер, эпизоды появляются по мере нахождения. Приложение ставится на Windows одним скриптом, ярлык поднимает API и сайт локально, данные не уходят в облако, кроме запроса к модели, если включён ИИ-анализ. Для точной реконструкции нужна дистанция до объекта и метки времени у видео камер.

Запасной вопрос про ML: прогноз «торможение по препятствию в ближайшие 10 с» даёт PR-AUC 0,07 против 0,026 у случайного (лифт около 2,7), ROC-AUC 0,76 при разбиении по вагонам. Как прогноз слабо, как разбор факторов полезно (ML_REPORT.md). В продукт не подключён.
